# Gartic Phone: album reveal (no capture, blocked)

**Why captured:** the model for ending on a shareable result. garticphone.com returned a Cloudflare block page to the automated browser, so there is no screenshot and I did not try to bypass it. Web search confirmed only the album exhibition at round end, where players flip through every chain, a host option for how the album is shown, and a ranking in Score mode. I could not verify any GIF export or share button, so treat that as unconfirmed.

**What to steal:** the idea that the end screen is a one-at-a-time, host-paced walk through the funny artifacts, not a leaderboard. For Jester: the reveal plays each player's cutout as its own beat, then a single "Save the clip" action as the final big button.

**What to skip:** copying claimed export features without checking them in the live app by hand.
